# Прицел Kagune Leap — визуальная логика

Визуальная логика вдохновлена официальной механикой The Ghoul в Dead by Daylight: ретикул используется для наведения Kagune Leap, а прицел связан с возможностью прыжка/захвата цели.

В этой версии ассеты DBD не копируются. Используются собственные текстуры челюстей мода. Челюсти появляются только при удержании Shift и наличии допустимой цели для Kagune Leap, плавно раскрываются/масштабируются при наведении и резко сходятся при запуске прыжка.

Каноническая база формы кагуне остаётся Tokyo Ghoul; DBD используется только как технический/визуальный референс для механики прыжка и поведения ретикла.
