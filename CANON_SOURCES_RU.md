# TokyoGhoulRPG — Canon Remaster Rules

## Главное правило проекта

**ВСЁ ДЕЛАЕМ ПО АНИМЕ TOKYO GHOUL И ПО ПРОВЕРЕННОЙ ИНФОРМАЦИИ ИЗ ИНТЕРНЕТА. НИЧЕГО НЕ ПРИДУМЫВАЕМ.**

Если внешний вид, способность или поведение нельзя подтвердить источником, оно не добавляется как каноническое.

## Использование DBD

DBD используется только как дополнительный референс для игровой реализации уже подтверждённого материала Tokyo Ghoul. Например, официальный DBD описывает Kagune Leap Канэки: кагуне цепляется за вертикальную поверхность и подтягивает персонажа вперёд. Это не используется для изменения канона Tokyo Ghoul.

## RC-типы

В выборе игрока используются четыре базовых RC-типа: Rinkaku, Ukaku, Koukaku и Bikaku. Старые экспериментальные слоты проекта (`Kagerō`, `Shooting`, `Long`) сохранены только ради совместимости старых сохранений и не считаются каноническими вариантами выбора.

## Важное ограничение

Текстуры 4.0.0 — процедурные 3D-материалы для UV-атласов, а не кадры, вырезанные из аниме. Они не выдаются за точную покадровую копию. Форма и движение кагуне адаптируются к 3D-модели Minecraft; конкретные канонические детали не добавляются без подтверждённого визуального источника. Если тип персонажа в доступных источниках спорный, он помечается как неуточнённый.
