# TokyoGhoulRPG — Anime Canon Remaster 4.0.0

Forge 1.20.1 / Java 17.

## КРИТИЧЕСКОЕ ПРАВИЛО КАГУНЕ
**Кагуне НЕ является предметом, блоком, бронёй или одеждой.** Оно существует как отдельная 3D-модель, прикреплённая к телу персонажа и визуально выходящая **именно со спины**. Точка крепления находится за торсом; кагуне не должно появляться спереди, сбоку или на голове. Активация клавишей G только включает/скрывает уже существующее тело-орган.

Официальный сайт Tokyo Ghoul описывает кагуне как хищнический орган, формируемый из RC-клеток, выделяемых из кагухо; он не описан как экипируемый предмет. Четыре базовых типа — Ukaku, Koukaku, Rinkaku и Bikaku.

## Главный принцип
**Tokyo Ghoul + проверенные источники. Ничего не выдавать за канон, если это не подтверждено источниками.** Игровые механики Minecraft (например, дерево навыков и Grapple) обозначаются как механики мода, а не как канонические события аниме.

## 8 профилей кагуне
- Полугуль: Канэки — Rinkaku; Сэйдо Такизава — Ukaku.
- Гуль: Ризе — Rinkaku; Тоука — Ukaku; Аято — Ukaku; Шу Цукияма — Koukaku; Нишики — Bikaku; Норо — Bikaku.
- Это 8 профилей персонажей, а не 8 новых RC-типов.

## Сборка
GitHub Actions собирает полноценный Forge JAR. Этот ZIP — **исходный проект**, не готовый JAR. После загрузки репозитория дождись зелёной сборки и забери JAR из artifact `TokyoGhoulRPG-4.0.0`.

# TokyoGhoulRPG — Anime Canon Remaster

Forge 1.20.1 / Java 17.

## Главный принцип
**Tokyo Ghoul + проверенные источники из интернета. Ничего не придумывать.**

Эта версия продолжает сохранённый FINAL_REMASTER_SOURCE и усиливает его визуальную базу без выдачи экспериментальных элементов за канон.

### Визуальный ремастер
- кагуне: 36 сегментов на ветвь;
- atlas кагуне: 1024×1024;
- Quinque item textures: 512×512;
- одежда/маски/броня: до 1024×1024;
- NPC/entity textures: до 512×512;
- boss entity texture: 1024×1024;
- более длинные анимационные импульсы: атака 12 тиков, способность 16, Rage 25, hit reaction 11;
- Grapple 20 тиков, Dash 24 тика;
- Rinkaku остаётся единственным канонически обоснованным grapple-профилем в этой версии, по референсу Kaneki из официального DBD Tokyo Ghoul chapter.

### Совместимость
Старые экспериментальные enum-слоты сохранены для чтения старых сохранений, но больше не появляются в новом каноническом выборе.


3.6.4: все 7 сохранённых визуальных вариантов кагуне доступны для выбора; добавлено двухстраничное дерево навыков с отдельными узлами техник кагуне/квинке, улучшен русский HUD и требования к техникам.
